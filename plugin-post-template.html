📋 Descrição

Este plugin permite aos administradores do servidor verem através das paredes para detectar cheaters e monitorar jogadores suspeitos. Inclui funcionalidades avançadas de detecção e ferramentas de administração.

✨ Características

  • 🔍 Visão através das paredes para admins
  • 🛡️ Sistema de detecção de cheats
  • 📊 Monitoramento em tempo real
  • 🎯 Marcação de jogadores suspeitos
  • ⚙️ Configurações personalizáveis

🏷️ Tags

admin esp wallhack anticheat monitoring

📖 Como Instalar

  1. Baixe o arquivo .amxx do plugin
  2. Faça upload para a pasta addons/amxmodx/plugins/
  3. Adicione o nome do plugin no arquivo plugins.ini
  4. Configure as permissões no users.ini (flag "d" para ESP)
  5. Reinicie o servidor ou digite amx_plugins reload

⚙️ Comandos

amx_esp - Liga/desliga o ESP

amx_esp_players - Mostra lista de jogadores

amx_esp_settings - Abre menu de configurações

📄 Requisitos

  • AMX Mod X 1.8.2 ou superior
  • Metamod 1.20 ou superior
  • Counter-Strike 1.6

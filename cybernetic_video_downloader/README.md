# Cybernetic Video Downloader

Uma ferramenta de download de vídeos com interface futurista e cybernética para Windows.

## Funcionalidades

- **Download de múltiplas plataformas**: YouTube, Twitch, TikTok e outras
- **Interface cybernética**: Design futurista com cores vibrantes (laranja, verde, roxo)
- **Informações completas**: Thumbnail, título, duração, tamanho estimado
- **Progresso em tempo real**: Velocidade, tempo restante, bytes baixados
- **Sistema de fila**: Múltiplos downloads com gerenciamento de prioridades
- **Controles avançados**: Pausar, retomar, cancelar downloads
- **Configurações flexíveis**: Qualidade, formato, pasta de destino

## Instalação

1. Instale Python 3.8 ou superior
2. Execute o instalador: `install.bat`
3. Execute o programa: `launch.bat`

## Uso

1. Cole o link do vídeo no campo URL
2. Aguarde as informações carregarem
3. Selecione a qualidade e formato desejados
4. Clique em "Download" para adicionar à fila
5. Gerencie os downloads através da interface

## Requisitos do Sistema

- Windows 10 ou superior
- Python 3.8+
- Conexão com a internet
- Espaço em disco suficiente

## Plataformas Suportadas

- YouTube
- Twitch
- TikTok
- Instagram
- Twitter
- E muitas outras (via yt-dlp)

## Desenvolvido com

- Python + Tkinter para interface
- yt-dlp para download de vídeos
- ttkbootstrap para tema moderno
- Pillow para processamento de imagens

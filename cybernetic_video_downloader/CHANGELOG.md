# Version History

## v1.0.0 - Initial Release
- Cybernetic interface design with futuristic styling
- Support for multiple video platforms (YouTube, Twitch, TikTok, etc.)
- Real-time video information extraction (thumbnail, title, duration)
- Download queue management with priority controls
- Progress tracking with speed and ETA display
- Pause, resume, and cancel download controls
- Quality and format selection (MP4, MKV, MP3, etc.)
- Custom download folder selection
- Windows .bat launcher files
- Settings management with persistent configuration
